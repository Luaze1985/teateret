# Issue Tracker

Issues use local Markdown in this repo.

## Default Location

- Use `docs/issues/` for issue files (create on first use).
- Do not create GitHub issues unless explicitly requested.

## Conventions

- Include affected area, acceptance criteria and validation command.
- Never include secrets, credentials or personal data in issue text.
