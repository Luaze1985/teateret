# Domain Docs

Single-context repo: Kildebelagt beslutningsbrief for Teateret basert på godkjente offentlige kilder og aggregerte driftsdata; ingen kundekommunikasjon eller automatisk publisering.

## Read Order

1. Root workspace `AGENTS.md` og `CONTEXT.md`
2. Local `AGENTS.md`, `README.md`
3. Relevant kode/innhold

## Rules

- `AGENTS.md` er styringskontrakt; hold scope-linjen oppdatert.
- Ikke `.env`, secrets, private datamapper.
